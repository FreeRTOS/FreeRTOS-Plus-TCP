◆ vNDRefreshCacheEntry()

void vNDRefreshCacheEntry ( const MACAddress_t *  pxMACAddress,
const IPv6_Address_t *  pxIPAddress,
NetworkEndPoint_t *  pxEndPoint 
)

Insert or refresh a fully-trusted ND cache binding as REACHABLE.

This is used for self-originated bindings that are not derived from received network traffic (e.g. the loopback interface mapping the endpoint's own MAC to its own loopback IPv6 address). Because the binding is trusted, it may create a new entry - unlike vNDRefreshCacheEntryAge(), which never inserts. Do NOT call this from the receive path for peer neighbours; that path must go through prvProcessNA()/prvDetermineAction().
